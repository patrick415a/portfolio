# 메일 폼 연결

Contact의 ‘메일 보내기’를 누르면 같은 창에서 `new_message.txt` 작성 화면을 엽니다. 이름, 답변받을 이메일, 내용은 모두 필수입니다. 입력값은 `PortfolioDesktop`의 메모리에 보관하므로 창을 최소화하거나 닫았다 다시 열어도 이번 방문 중에는 유지됩니다. 새로고침하면 초기화됩니다.

`src/lib/contact.ts`의 `sendLetter`를 폼의 `onSend`에 연결했습니다. 브라우저에서 Web3Forms로 직접 POST하며, 제목은 `[포트폴리오] 이름님의 메시지`, 발신자 이름은 `이성호 포트폴리오`입니다. 폼의 `replyTo`는 Web3Forms의 `email` 필드로 전달되어 회신 주소가 됩니다.

## 환경 변수와 수신 주소

루트 `.env.local`의 기존 `VITE_WEB3FORMS_ACCESS_KEY`를 `next.config.ts`에서 읽습니다. Next.js 표준 이름인 `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY`도 지원하며, 둘 다 있으면 표준 이름이 우선합니다. 키 변경 후에는 개발 서버를 재시작해야 합니다. 배포할 때에도 빌드 환경에 해당 변수를 설정해야 합니다. 키 값은 코드에 직접 적거나 로그에 출력하지 않습니다.

Web3Forms Access Key는 브라우저 공개용으로 설계되어 클라이언트 번들 및 전송 요청에서 확인할 수 있습니다. SMTP 비밀번호 등의 비밀 키를 여기에 넣으면 안 됩니다. [공식 설명](https://docs.web3forms.com/getting-started/faq)

실제 메일 수신자는 Access Key를 발급받은 이메일입니다. `profile.email`을 바꿔도 수신자는 변경되지 않습니다. 현재 연락처 정보는 `patrick415@gmail.com`이며, 해당 주소로 발급받은 키를 사용해야 그 주소로 수신됩니다.

## 전송 동작

전송 중에는 중복 요청을 막고 입력을 잠급니다. 15초가 지나면 요청을 중단하고 안내합니다. 성공 응답을 받은 뒤에만 입력을 비우고 완료 메시지를 표시하며, 실패하면 작성 내용을 유지합니다. 요청 제한(429), 시간 초과, 네트워크 오류를 구분해 안내합니다. 키가 없으면 전송 버튼을 비활성화합니다.

발송 로직은 모의 응답으로 검증합니다. 실제 메일 도착 확인은 폼에서 직접 전송한 뒤 받은편지함과 스팸함을 확인해야 합니다.
